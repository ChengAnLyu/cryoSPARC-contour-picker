SARU Picker 2.8.0 — Windows CPU edition

Install once and open SARU Picker from the Start menu. Python, its libraries,
and the SAM ViT-B model are included.

CUSTOM ICON DOWNLOAD: Extract the WHOLE ZIP before installing. Keep app-icon.png
and app-icon.ico in the same folder as the setup EXE. Setup copies them into the
application and updates the app/shortcut icons. Setup itself has a geometric
icon; launching the installed application shows your supplied portrait. Setup
without these optional files uses the geometric fallback throughout.

LEARNED CAPSIDS: If capsid-profile.json is included, keep it beside the setup
EXE as well. Setup places it beside the SAM model. Select Advanced > Detection
profile > capsid-learned to try the experimental trained detector. No separate
model download is needed. The default capsid detector keeps the earlier texture
heuristic even when the learned profile is installed.

cryoSPARC remains your live image viewer. Keep it on the primary monitor.
The control panel stays visible and above the drawing/selection overlays.
Its size adapts to Windows text scaling so terminate remains fully visible.

MANUAL — original interaction
1. Choose manual and uncheck Disable Picking.
2. Hold the left mouse button and trace a shape directly over the micrograph.
3. Release to fill the contour with picks. Draw the next contour when finished.
The original spacing slider (5–25 pixels, default 13), bbox-anchored hex grid
and zero inset are preserved. Picking uses the same adjustable 0.01-second
default click delay as semi-auto and auto. The previous outline is cleared
before a new stroke appears; the control panel stays visible.
Manual mode has no screenshot, screen-area selection, model or separate review
step. A stroke starts immediately and release directly starts picking.

REPEATED SELECTIONS (2.7.2)
After a contour finishes, overlapping proposals with no new pick positions are
hidden. Each remaining proposal is checked against actual completed picks.
A covered selection now says it is already covered, and a contour with no grid
sites reports the current spacing. Later valid contours remain selectable.
When none remain, the status points to Next micrograph or Detect. The log records
raw, blocked, eligible and sent counts. This selection behavior is retained in
2.8.0, along with the 3,500-screen-pixel automatic capsid cutoff.

SEMI-AUTO
Move the panel outside the intended micrograph area. Select screen area,
drag around the micrograph, then Detect. The panel remains visible throughout. Green outlines
appear directly over cryoSPARC. Enable picking and click inside a target
contour. The program waits for your mouse release, hides its annotation layer,
then fills only that contour. The panel stays visible and the remaining outlines
return on a fresh drawing window so completed contours are not remapped.
Box prompt provides guided selection.
Next micrograph replaces Next alternative. It sends Down once to cryoSPARC,
waits for a different stable image, and detects fresh contours in the same
screen area. It does not pick them until you click a contour. This also works
with Disable Picking checked, so you can navigate and review without picking.
The next contour is enabled after completed picks are recorded. Delayed marker
painting around those known picks is ignored when checking image movement.
Each contour has its own manual-style spacing grid, zero inset and the shared
0.01-second default click delay. Previously placed or nearby picks are not repeated.

AUTO
Select the screen area, enable picking and Start auto.
The app fills every contour one after another, showing contour/pick progress.
If Detect already displayed contours, Start auto reuses that exact set after
checking the screen still matches. Otherwise it detects first. After each
micrograph it uses Down once, waits for a new stable image, detects, picks,
and repeats. Same-scene detection retains previous pick locations.
Limit (0=all) defaults to 0 for continuous operation. Set 1 for the current
image only, or 2-1000 for a bounded run. Positive limits include the current
image and empty images. Images with no detected contours are counted and
skipped while the limit allows.
Load (s), default 10, is the maximum loading timeout. The app continues sooner
when a changed image becomes stable. An unchanged/end-of-list view, a recently
repeated image, a loading timeout, or lost focus stops the cycle. It does not
send repeated Down-key retries.

PICKING SPEED
Manual, semi-auto and auto share a 0.01-second default delay between clicks.
Set 0.00 for no added inter-click delay, or increase the value if cryoSPARC
does not register every pick. Open settings through Advanced in model modes,
press F9 while the SARU panel has focus, or right-click the panel and choose
"Picking speed…". The compact manual layout stays the same.
Zero delay still yields between clicks. Per-click cancellation, focus and
position checks, and the mouse fail-safe remain enabled. Windows and the
browser still need time to process picks; detection and image loading are
separate. Use the lowest setting that registers reliably on your workstation.

DETECTION
The private 2.8.0 profile is trained with examples 1-120. It uses confirmed
large-capsid markings as positives and 43 confirmed blank images as negatives.
Small markings and unmarked areas in other images remain unknown. Negative
training includes carbon edges, debris and other unwanted structures within
the confirmed blank images. Model selection balances blank-image false picks
against coverage of known large capsids. Final shape and carbon checks apply.
Strong compact cores can now receive an additional tight SAM prompt when their
weaker surrounding support previously hid them. Original prompts retain their
priority and the same 24-prompt limit. Final polygon size is checked before
overlap suppression, so a rejected small fragment cannot hide a larger contour.

The default capsid profile retains the earlier texture heuristic. The
capsid-learned option uses the experimental appearance model to locate dense
granular interiors and guide SAM; it requires capsid-profile.json. Polygonal
boundaries are used for both display and picking. Development results include
recovered targets, missed known targets and unwanted background regions, so
this option has not replaced the default detector. Its screen selection must
contain no more than 4,194,304 pixels; select a smaller region if asked.
Neither path guarantees every target or excludes every membrane fragment.
The learned score is not a calibrated capsid probability; SAM weights remain
unchanged. Unmarked regions in nonblank examples are not negative labels.
Review the contours in semi-auto before running automatic picking.
Advanced > Detection profile > generic restores unclassified SAM proposals.

CARBON FILM EDGES
Both capsid profiles check the clean screen image for very long, nearly straight
support-film edges. The app rejects an elongated contour when a substantial
part of its boundary follows such an edge. Nearby compact capsids are assessed
individually; the app does not exclude an entire side of the film or use image
darkness alone. Short polygon facets are not enough to reject a capsid.
Curved support and ambiguous broad regions can still produce unwanted contours.
This check uses the existing image and models; no additional download is needed.
Manual picking, generic detection and explicit box/point prompts keep their
existing behavior.

Escape stops and disables picking. Space pauses/resumes active auto; F8 is an
additional pause key. Disable Picking removes the input-catching overlay.
Keep micrograph zoom and position fixed; select/detect again after changes.

Settings include the model options as well as shared picking speed. This edition is CPU
only, so use Auto or CPU device selection. Recognition still needs the model's
memory and computation. The included checkpoint is unchanged; no extra model
download is required for the capsid profile.

Logs: %LOCALAPPDATA%\SARU_Picker
If the program exits unexpectedly, preserve saru_picker.log, startup.log and
native_fault.log in this folder. Native-fault logs are normally empty.
Third-party notices and model information: installed _internal folder
Optional snapshot review editor: launch with --review

LARGE-ONLY AUTOMATIC DETECTION (2.7.1)
Both capsid profiles now skip final connected regions below 3,500 screen pixels.
Advanced > Minimum capsid area (screen px²) changes this cutoff; 0 allows all
sizes. Zoom changes apparent size. Manual drawing and Box prompts are unchanged.
Changing recognition settings clears old proposals; choose Detect again.
The size filter is retained in 2.8.0 alongside the updated 120-example profile.
