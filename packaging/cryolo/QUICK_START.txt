SARU Picker 3.0.0 — four profiles, offline inference

1. Extract the delivered installer and model files into the same folder.
   If supplied as two ZIPs, extract both into the same destination and open
   their shared SARU-Picker-3.0.0 folder. Keep cryolo-capsids.onnx,
   cryolo-config.json, capsid-profile.json and the icons beside
   SARU-Picker-Setup-3.0.0-win64.exe, then run Setup.
2. Launch SARU Picker 3.0. No internet connection, Python selection, runtime
   installation or repair step is needed.
3. Choose a Detection profile in Advanced:

   capsid          SAM with existing capsid filtering (default).
   capsid-learned  SAM with the supplied learned appearance profile.
   generic         SAM without capsid-specific automatic filtering.
   crYOLO          The exported trained crYOLO detector, evaluated by bundled
                   ONNX Runtime CPU, then refined into learned contours.

SAM ViT-B, the CPU engines and the application executable are included. Each
profile keeps the appropriate model path. The ONNX model contains its own
preprocessing and detector metadata. Inspect detections at normal screen zoom.
Manual, semi-auto and auto controls, screen selection, sampling spacing, click
delay, cancellation and Next micrograph remain available. The default minimum
capsid contour area is 3,500 screen pixels; generic and explicit SAM prompts
retain their prior rules.

crYOLO predicts boxes. Image-based processing refines them into contours;
these are not guaranteed biological boundaries. crYOLO box/point prompts
select detections. SAM profiles retain SAM interactive segmentation.

This offline update retains version 3.0.0 and upgrades the previous 3.0 edition
in place. Setup no longer prepares a separate crYOLO runtime. It removes old
owned runtime installer helpers; the old private Python environment is left
untouched and is no longer needed for normal detection. Global Python, PATH
and the separate legacy SAM 2.9 installation remain unchanged. The internal
EXE keeps its upgrade-compatible name: SARU Picker crYOLO.exe.

Known default H5 selections move to the verified matching ONNX export. A custom
H5 model needs a matching export; it does not start a runtime installation.
The Repair crYOLO runtime control has been removed.

Detector settings:
  %LOCALAPPDATA%\SARU_Picker\detector-settings.json
Prediction failure details:
  %LOCALAPPDATA%\SARU_Picker\cryolo-prediction.log

UPGRADE MODEL PATH CORRECTION
Saved selections of the supplied cryolo-capsids.h5 automatically find the
matching installed cryolo-capsids.onnx, even when the old H5 folder is gone.
The matching appearance profile is loaded beside the effective ONNX model.
Install over the existing application to keep installed models. If the model
is missing, extract the models ZIP beside Setup and run Setup again.

Portable alternative
  Extract the entire GUI ZIP. Put the model/config/profile in
  SARU_Picker_crYOLO/_internal/models and icons in _internal/assets.
  Launch SARU Picker crYOLO.exe. Keep the EXE and _internal folder together;
  do not run inside the ZIP. This also works offline.

Model provenance
  This application update exports existing trained weights; it does not claim
  a new training run. The supplied model record identifies training and export
  hashes and numerical checks. Public Windows checks use synthetic models to
  exercise real inference and positive contours, not assess capsid accuracy.
  Stock crYOLO software and general pretrained weights are not redistributed.
  Third-party license notices are included under _internal/licenses.

AUTO PICKING UPDATE (22 November 2026)
Auto no longer compares screenshot pixels before, during or after picking,
or against the old reference before Down. Marker redraws can continue without
stopping the run. Pause, Escape, target-window and click-area checks remain.
After Down, the app still waits for a different, stable micrograph. Semi-auto
and recognition alignment checks are unchanged. Existing offline models can
be reused; this is an application-only update, still version 3.0.0.
