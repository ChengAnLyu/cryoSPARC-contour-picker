SARU Picker 3.0.0 — four detection profiles

1. Extract the whole delivered release ZIP. Keep cryolo-capsids.h5,
   cryolo-config.json, capsid-profile.json, app-icon.ico and app-icon.png beside
   SARU-Picker-Setup-3.0.0-win64.exe, then run Setup.
2. Wait for Setup to prepare the crYOLO runtime automatically. The first
   installation requires internet access and can take several minutes.
   Python selection and a separate runtime-install step are not required.
   If setup fails, restore the internet connection and run Setup again.
3. Launch SARU Picker 3.0. Choose a Detection profile in Advanced:

   capsid          SAM with the existing capsid filtering (default).
   capsid-learned  SAM with the supplied learned appearance profile.
   generic         SAM without capsid-specific automatic filtering.
   crYOLO          crYOLO detections refined into contours with the supplied
                   learned appearance profile.

The SAM ViT-B model, its CPU runtime and the private Python executable package
used by crYOLO are included. Each detector keeps its
own model path when changing profiles. No Python executable needs to be chosen.
Manual, semi-auto and auto controls, screen selection, sampling spacing, click
delay, cancellation and Next micrograph remain available as before. Inspect
results at the normal screen zoom. The default minimum capsid contour area is
3,500 screen pixels; SAM generic and explicit SAM prompts keep their prior rules.

crYOLO predicts boxes. SARU's image-based processing refines those regions into
contours; these are not guaranteed biological boundaries. crYOLO box/point
prompts select detections. SAM profiles retain SAM interactive segmentation.

This installer upgrades the previous crYOLO 3.0 edition in place while retaining
its owned install/runtime folders. The separate legacy SAM 2.9 installation is
not replaced. The internal EXE retains its old name for this upgrade:
  SARU Picker crYOLO.exe
The visible application and shortcuts are SARU Picker 3.0.

crYOLO is downloaded from its upstream distribution into a private environment.
It is provided for non-commercial academic/research use under its own license:
  https://cryolo-doc.readthedocs.io/en/stable/other/license.html
No system PATH, file associations or global Python installation are changed.

Runtime setup and diagnostic report:
  %LOCALAPPDATA%\SARU_Picker_crYOLO\runtime-install-report.json
Detector settings:
  %LOCALAPPDATA%\SARU_Picker\detector-settings.json

Training provenance
  The independent training/train_cryolo.py wrapper runs stock crYOLO model,
  loss, augmentation and checkpoint APIs in a separate Python 3.7 process.
  Monitoring explicitly averages every equal-size batch. Full-fit monitoring
  uses the same 160 examples and is not held-out validation. Consult the
  supplied model record for completed epochs and hashes. Changing the app to
  3.0.0 or adding profile selection does not itself retrain either model.

Portable alternative
  Extract the entire GUI ZIP. Place the three private model/config/profile
  sidecars in SARU_Picker_crYOLO/_internal/models and the supplied icons in
  _internal/assets. Launch SARU Picker crYOLO.exe. The crYOLO profile prepares
  its private runtime automatically when first needed, with internet access.
  The EXE and its _internal folder must remain together; do not run inside ZIP.

Build checks execute real SAM and stock crYOLO inference on synthetic data,
including the frozen application's external-process boundary. Those checks
validate packaging and runtime operation, not trained-model biological accuracy.
