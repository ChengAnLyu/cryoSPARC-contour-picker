SARU Picker generic application artwork

The repository contains a geometric fallback icon, generated by
packaging/generate_fallback_icon.py. It contains no uploaded artwork.
app-icon.ico includes 16, 24, 32, 48, 64, 128, and 256 pixel entries.

Optional private installer sidecars

An installer distribution can include app-icon.png and app-icon.ico beside
SARU-Picker-Setup-<version>-win64.exe. Extract the complete ZIP to a folder,
then run Setup from that folder. Setup copies any present sidecars over the
installed fallback assets. The icon helper applies the installed ICO to the
installed application executable before the application is launched.

The window icon, shortcuts, and uninstall entry use those installed assets.
Running only the Setup EXE without its sidecars keeps the generic icon.
Neither the application nor the installer uploads sidecar artwork.
